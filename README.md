# MyQuant

Oxford Engineering Science | Quant-first finance preparation

This repository is a 30-day preparation workspace for quantitative finance, Oxford finance societies, and early-career applications. It is designed to produce evidence of work, not just a list of courses.

## Start here

1. Open [the daily learning checklist](learning/30_day_schedule.md) and begin with Day 1.
2. Read [the linked resource list](learning/resources.md). Every resource has a stage, time budget, and expected output.
3. Run the quantitative research project in [momentum_research](momentum_research/).
4. Run the derivatives project in [option_lab](option_lab/).
5. Use [the interview bank](learning/interview_bank.md), [the application tracker](applications/application_tracker.csv), and [the CV template](cv/cv_template.md).

## Target outcomes

- A reproducible ETF momentum research report with out-of-sample evaluation.
- A tested Black-Scholes, Monte Carlo, and delta-hedging lab.
- A semiconductor / AI infrastructure stock pitch based on public filings.
- A one-page English CV that only claims work that can be defended in interview.
- Timed practice across the three areas disclosed by Oxford Alpha Fund Quant: mathematical problem solving, programming, and financial analysis.

## Data and research discipline

The research code downloads public historical prices from Yahoo Finance's chart endpoint when the user runs it. Raw data are cached locally and should not be committed until the user has reviewed licensing and privacy implications. All performance numbers are research outputs, not investment advice.

## Recruiting context

Oxford Careers recommends that students investigate Spring Weeks early and notes that quantitative finance interviews often test probability, estimation, mental maths, coding, and structured problem solving. The exact eligibility of each programme varies, especially for a four-year MEng, so the tracker is part of the deliverable rather than an optional extra.
